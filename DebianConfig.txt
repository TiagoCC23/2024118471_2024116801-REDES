Debian:
sudo modprobe bonding
sudo ip link add name bond0 type bond mode active-backup
sudo ip link set ens4 down
sudo ip link set ens5 down
sudo ip link set master bond0 dev ens4
sudo ip link set master bond0 dev ens5
sudo ip link set up dev bond0

Coisas que aconteceram:

Para ficar sempre ativo(não sei se vai adiantar) é preciso adicionar:
sudo nano /etc/network/interfaces

auto bond0
iface bond0 inet manual
bond-slaves ens4 ens5
bond-mode active-backup
bond-miimon 100

auto bond0.30
iface bond0.30 inet static
address 10.50.0.200
netmask 255.255.255.224
vlan-raw-device bond0
